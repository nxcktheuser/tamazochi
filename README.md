# Tamazochi

Прототип игры для Telegram Mini Apps. Текущее название внутри приложения — Wasteland Home.

## Устройство
- `index.html` — интерфейс, Canvas-графика и игровая логика в одном файле.
- В коде есть создание героя (имя, пол, цвет кожи), потребности, убежище на фоне-картинке с улучшениями, склад, экипировка, крафт и вылазки на карту города.
- Картинки лежат в `assets/` (герои, комнаты, референс стиля).
- Сохранение предусмотрено в localStorage и Telegram CloudStorage. Серверная часть в этом репозитории отсутствует.

## Просмотр
Открой index.html в браузере для предварительного просмотра. Интеграцию с Telegram и облачные сохранения проверяй отдельно внутри Telegram Mini App. Сборка проекта не требуется.

## Текущая работа
Подготовка фоновых картинок локаций для вертикального экрана телефона. Направление: детализированный пиксель-арт, советская панельная архитектура, потёртые бетон и металл, холодная российская постапокалиптическая атмосфера.

Обсуждаются личная комната, главное лобби, торговцы, мастерская и фон возвращения с вылазки. Эти новые фоны ещё не созданы и не внедрены; упоминание локаций не означает наличие всех соответствующих механик.

## Стиль графики
Утверждённое направление и правила для ассетов лежат в [STYLE_GUIDE.md](STYLE_GUIDE.md), референс — `assets/style/style-board.png`. Ассеты по этому стилю ещё не созданы и не внедрены.
