# Workflow — совместная работа над проектом

## Структура веток

```
main          — стабильная версия (игра работает всегда)
design/...    — дизайн (CSS, Canvas, разметка)
fix/...       — функциональные правки
```

**Никогда не держите больше 1 временной ветки одновременно.**

## Как работает функционал

1. `git pull` перед началом
2. `git checkout -b fix/название`
3. Правите файлы своей зоны (см. OWNERS.md)
4. `node --check` — проверяете синтаксис
5. `git commit -m "короткое описание"`
6. `git push origin fix/название`
7. `git checkout main && git merge fix/название && git push`

## Как работает дизайн

1. `git pull` перед началом
2. `git checkout -b design/название`
3. Правите только: `style.css`, `js/ui.js`, `js/render.js`, `assets/`
4. `node --check` — проверяете синтаксис
5. `git commit -m "короткое описание"`
6. `git push origin design/название`
7. **Функционал мержит дизайн в main** — проверяет, что игра не сломалась

## Правила

- Перед работой: `git pull`
- Коммиты: маленькие, по одному факту
- Перед пушем: `node --check` проходит
- Дизайн → main: только функционал мержит (знает, что сломается)
- Функционал → main: кто угодно, но с проверкой
- Перед работой над чем-то крупным: обсудите с напарником
- Если сломали — откатите (`git revert`), не чините на лету
